# Сервис Капчи (api-captcha)

Сервис предназначен для создания и проверки визуальных капч, чтобы защитить систему от ботов.
Данные о состоянии каждой капчи (её решение и статус) хранятся в Redis с ограниченным временем жизни (TTL).

## Технологический стек

- **Spring Data Redis**: работа с Redis как основным хранилищем состояния.
- **EasyCaptcha**: библиотека для генерации изображений капчи.

## Принцип работы (Защита от Replay Attack)

Для предотвращения повторного использования одной и той же капчи (Replay Attack) реализована следующая логика:

1. Капча генерируется (`CREATED`, TTL 5 мин).
2. Пользователь присылает решение. Если оно верно, статус меняется на `SOLVED`, а TTL сокращается до 10 секунд.
   То есть после прохождения captcha должен сразу же отправиться изменяющий запрос.
3. При попытке создать новость, сервис `api-news` обращается к эндпоинту `checkAndExpire`, который немедленно удаляет
   запись из Redis после первой же успешной проверки.

## API Эндпоинты

### Публичный API (для Frontend)

#### 1. Генерация новой капчи

`POST /captcha/generate`

**Назначение:** Генерирует случайную буквенно-цифровую капчу и возвращает её ID и картинку (base64).

- **Принимает:** Параметры не требуются.
- **Возвращает:** Объект `CaptchaResponse`.
    - `id` (UUID): Уникальный идентификатор капчи.
    - `imageBase64` (String): Изображение капчи в кодировке Base64 (готово для вставки в `<img src="...">`).

#### 2. Решение капчи

`POST /captcha/{id}/solve`

**Назначение:** Проверка ответа пользователя на сервере.

- **Принимает:**
    - `id` (UUID) в пути.
    - `answer` (String) в теле JSON (SolveRequest).
- **Возвращает:** Объект `SolveResponse`.
    - `solved` (boolean): `true`, если ответ верен, иначе `false`.
    - `message` (String): Комментарий к результату.

---

### Внутренний API (для сервисов)

#### 3. Проверка и немедленное удаление

`POST /internal/captcha/{id}/checkAndExpire`

**Назначение:** Используется другими сервисами для подтверждения, что пользователь действительно решил капчу.

- **Принимает:** `id` (UUID) в пути.
- **Возвращает:** Объект `CheckCaptchaResponse` (поле `valid`).
- **Примечание:** После этого вызова капча немедленно удаляется из Redis, что гарантирует одноразовость использования
  решения.
