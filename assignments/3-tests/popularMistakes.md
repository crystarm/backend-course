# Популярные ошибки 3 лабораторной

## Неуместное использование setUp

Метод setUp нужен для важной предподготовки: дополнительной инициализации моков и классов, конфигурации подключений, в
крайнем случае для очистки.

Чрезвычайно плохо создавать в нем обычные dto. В рамках тестов
они обычно никак не меняются и используются просто как константы, не нужно их каждый раз заново пересоздавать.

## Неправильное расположение тестов

Тесты должны быть расположены в той же структуре, что и классы, которые они тестируют.
