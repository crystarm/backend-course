# 1 лабораторная работа

**Выбери [вариант](variants.md) в соответствии со списком из google-класса**

В этой лабораторной работе вы закрепите навыки работы с файлами и коллекциями в Java.

## Задание

Дан CSV-файл с информацией о персонажах из сериала «Rick and Morty».
Каждый студент получает одинаковый исходный текстовый файл [characters.csv](characters.csv), но разные варианты задания.

Задание состоит из трёх этапов:

### 1) Чтение данных из файла

Загрузить данные в определённую коллекцию (List, Set, Map, TreeMap, PriorityQueue и т.д.).

### 2) Обработка данных

Выполнить над ними конкретные операции (сортировка, группировка, поиск уникальных значений, подсчёт статистики, выборка топ-N и т.п.).
Коллекция и операция подобраны так, чтобы вам пришлось использовать сильные стороны именно этой коллекции.

### 3) Запись результата обратно в файл

После обработки сохраните результат в новый CSV/текстовый файл.
Формат вывода должен быть аккуратным и понятным (например: json, ключ → значение, status, count, список имён через запятую и т.д.).

## Дополнительное задание (не отменяет основное)

Реализовать дополнительные методы для создания/обновления/удаления (CRUD) персонажей в изначальном csv-файле.

**Дополнительное задание будет проверяться ТОЛЬКО в том случае, если вы сдали основное задание на максимум баллов.**

## Правила оценивания

* 10 баллов — базовое выполнение работы, ответы на вопросы по коду
* 5 баллов — ответы на вопросы по варианту коллекции и ее отличиях от других
* 5 баллов — дополнительное задание (CRUD операции) — только если предыдущие пункты выполнены на отлично

Итого вы можете получить до 20 баллов.
