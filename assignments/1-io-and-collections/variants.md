## Варианты заданий

1. List — сортировка по дате создания

Считать персонажей в List.
Отсортировать по полю created от старых к новым.
Записать обратно в файл отсортированный список.

2. HashSet — уникальные планеты происхождения

Считать персонажей в HashSet<String>, где хранятся только значения origin/name.
Вывести все уникальные планеты происхождения и сохранить их в отдельный файл.

3. TreeSet — уникальные имена в алфавитном порядке

Считать всех персонажей в TreeSet<String> по полю name.
Таким образом получится список имён без повторов, отсортированный по алфавиту.
Записать результат в файл.

4. HashMap<String, Integer> — количество персонажей по статусу

Считать в HashMap, где ключ = status (Alive, Dead, unknown), значение = количество персонажей с этим статусом.
Записать результат в файл в виде status, count.

5. TreeMap<String, List<String>> — группировка по видам (species)

Считать в TreeMap, где ключ = species, значение = список имён персонажей.
Записать результат в файл в формате: species → [name1, name2, ...].

6. LinkedHashMap<String, String> — соответствие персонажа и его текущей локации

Считать в LinkedHashMap, где ключ = name, значение = location/name.
Сохранить пары персонаж → локация в файл, сохранив порядок из исходного CSV.

7. Map<String, List<String>> — группировка по полу

Считать в Map, где ключ = gender, значение = список персонажей этого пола.
Записать результат в файл.

8. PriorityQueue — топ-5 самых «старых» по created

Считать в PriorityQueue, отсортированную по дате created.
Достать из очереди первые 5 персонажей (самых ранних по времени создания).
Записать их в файл.

9. HashSet<String> — уникальные комбинации (species, gender)

Считать в HashSet строки вида "species - gender".
В файл сохранить все уникальные комбинации видов и полов.

10. Map<String, Long> — количество персонажей по origin

Считать в Map, где ключ = origin/name, значение = количество персонажей с этого origin.
Сохранить результат в файл в формате origin, count.

11. Deque (например, ArrayDeque) — обход «с обоих концов»

Загрузить персонажей в Deque.
Удалять по одному элементу сначала с головы, потом с хвоста, чередуя.
Сохранить порядок извлечённых имён в файл.

12. Stack — обратный порядок появления

Загрузить всех персонажей в Stack (по порядку из CSV).
Выгрузить обратно в файл, но в обратном порядке (LIFO).

13. LinkedList — фильтрация по полу

Считать персонажей в LinkedList.
Удалить из списка все элементы с gender = unknown.
Сохранить оставшихся персонажей в файл, сохранив порядок.

14. EnumMap<Status, List<String>> — группировка по статусу

Создать enum Status {ALIVE, DEAD, UNKNOWN}.
Считать в EnumMap, где ключ = статус, значение = список имён.
Сохранить результат в файл в формате ALIVE → Rick, Morty.

15. LinkedHashSet<String> — уникальные локации в порядке появления

Считать всех персонажей в LinkedHashSet<String> по полю location/name.
Такой сет сохранит порядок первой встречи и уберёт повторы.
Сохранить результат в файл: список уникальных локаций в порядке их появления в исходном CSV.

16. TreeMap<String, Set<String>> — уникальные origin → species

Считать в TreeMap, где ключ = origin/name, значение = множество уникальных видов (species).
Сохранить результат в файл: каждая строка = origin → [species1, species2, …].

17. SortedSet<String> — персонажи без дубликатов по имени и отсортированные

Считать имена персонажей в SortedSet<String>.
Записать результат в файл — имена без повторов, по алфавиту.

18. Hashtable<String, List<String>> — группировка по gender

Считать в Hashtable, где ключ = gender, значение = список имён.
Сохранить результат в файл.

19. PriorityQueue — топ-3 по длине имени

Считать персонажей в PriorityQueue, где приоритет = длина имени.
Извлечь 3 самых длинных имени и записать их в файл.

20. Map<String, Map<String, Integer>> — вложенная группировка

Считать в Map, где ключ 1 уровня = species, ключ 2 уровня = status, значение = количество персонажей.
Записать результат в файл.

21. ArrayList — сортировка по длине имени

Считать персонажей в ArrayList. 
Отсортировать по длине поля name от длинных к коротким. 
Записать отсортированный список в файл.

22. Vector — сортировка по статусу  

Считать персонажей в Vector. 
Отсортировать по полю status (сначала Alive, затем Dead, unknown). 
Записать результат в файл.

23. HashSet<String> — уникальные типы (type)  

Считать в HashSet значения поля type. 
Вывести все уникальные типы и сохранить их в файл в произвольном порядке.

24. TreeSet<String> — уникальные статусы в лексикографическом порядке  

Считать в TreeSet значения поля status. 
Получить отсортированный список уникальных статусов. 
Записать результат в файл.

25. HashMap<String, List<String>> — группировка по локации  

Считать в HashMap, где ключ = location/name, значение = список имён персонажей. 
Записать результат в файл в формате location → [name1, name2, ...].

26. TreeMap<String, Integer> — количество по полу, отсортировано по ключу  

Считать в TreeMap, где ключ = gender, значение = количество персонажей. 
Сохранить результат в файл в виде gender, count.

27. LinkedHashMap<String, Integer> — количество по видам в порядке появления  
    
Считать в LinkedHashMap, где ключ = species, значение = количество. 
Сохранить порядок первой встречи видов. Записать результат в файл.

28. PriorityQueue — топ-5 самых «новых» по created  
    
Считать в PriorityQueue, отсортированную по дате created в обратном порядке (от новых к старым). 
Извлечь первые 5 и записать в файл.

29. HashSet<String> — уникальные комбинации (status, species)  
    
Считать в HashSet строки вида "status - species". 
Сохранить все уникальные комбинации статусов и видов в файл.

30. Map<String, Long> — количество персонажей по локации  

Считать в Map, где ключ = location/name, значение = количество персонажей. 
Сохранить результат в файл в формате location, count.

31. Deque (ArrayDeque) — чередование добавления спереди и сзади  
    
Загрузить персонажей в Deque. 
Добавлять элементы чередуя: один спереди, один сзади. 
Затем извлечь все в файл в получившемся порядке.

32. Stack — симуляция отмены операций  
    
Загрузить персонажей в Stack. Выполнить pop() для последних N элементов (например, 10), симулируя отмену. 
Записать оставшийся стек в файл в обратном порядке.

33. LinkedList — вставка элементов в середину  
    
Считать персонажей в LinkedList. 
Вставить в середину списка новых вымышленных персонажей (создать вручную). 
Сохранить обновленный список в файл.

34. EnumMap<Gender, Integer> — подсчёт по полу  
    
Создать enum Gender {MALE, FEMALE, UNKNOWN, GENDERLESS}. 
Считать в EnumMap, где ключ = gender, значение = количество. 
Сохранить результат в файл в формате MALE → count.

35. LinkedHashSet<String> — уникальные виды в порядке появления  
    
Считать в LinkedHashSet значения поля species. 
Сохранить уникальные виды в порядке их первого появления в CSV и записать в файл.

36. TreeMap<String, Set<String>> — уникальные локации → genders  
    
Считать в TreeMap, где ключ = location/name, значение = множество уникальных полов (gender). 
Сохранить результат в файл: location → [gender1, gender2, …].

37. SortedSet<String> — имена по длине
    
Считать имена в SortedSet с компаратором по длине name. 
Записать результат в файл — имена без повторов, отсортированные по длине.

38. Hashtable<String, Integer> — количество по статусу  
    
Считать в Hashtable, где ключ = status, значение = количество. 
Сохранить результат в файл.

39. PriorityQueue — топ-3 по кратчайшему имени  
    
Считать персонажей в PriorityQueue с приоритетом по длине имени (от коротких к длинным). 
Извлечь 3 самых коротких и записать в файл.

40. Map<String, Map<String, Long>> — вложенная группировка по gender → origin  
    
Считать в Map, где ключ 1 уровня = gender, ключ 2 уровня = origin/name, значение = количество. 
Записать результат в файл в nested формате.
