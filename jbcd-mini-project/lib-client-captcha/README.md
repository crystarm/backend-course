# Клиентская библиотека Капчи (lib-client-captcha)

Библиотека-клиент для упрощения взаимодействия микросервисов с `api-captcha`.
Позволяет избежать дублирования кода при вызове API проверки капчи.
Подключается к разным сервисам для интеграции с `api-captcha`.

## Основные возможности

- **CaptchaClient**: Клиент для вызова внутреннего API сервиса капчи.
- **DTO**: Содержит общие объекты ответов.
