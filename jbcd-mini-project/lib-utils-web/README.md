# Утилиты Web (lib-utils-web)

Общая библиотека для всех web-сервисов проекта, обеспечивающая единообразную обработку ошибок и формат ответов.

## Основные возможности

- **BaseException**: Базовый класс для всех бизнес-исключений.
- **GlobalExceptionHandler**: Контроллер-адвайзер, который перехватывает исключения и возвращает JSON в
  стандартизированном формате.
- **Error Response**: Стандартизированная структура ошибки (код, сообщение).
