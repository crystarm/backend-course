# Что такое SSH-ключ

SSH-ключ — это способ авторизации без пароля. Он состоит из двух файлов:
* Приватный ключ — хранится только на вашем компьютере (никому не передаётся!)
* Публичный ключ — его мы добавляем в сторонние ресурсы: сервера/GitHub/GitLab/e.t.c

Смысл этой технологии в том, чтобы представить наш компьютер другому ресурсу без использования пароля 
(не придется каждый раз вводить nickname/password при каждом pull/push в репозиторий).
По сути, ssh-ключ это уникальный ключ вашего компьютера, по которому все ресурсы смогут вас узнавать (после регистрации).
Как правило, нужно сгенерировать ключ один раз на каждый компьютер и больше не трогать. Не удаляйте ваш файл.
По одному ключу вас будут узнавать все ресурсы, которым вы зарегистрируете ключ.

В данном туториале мы рассмотрим как создать SSH-ключ и как его использовать для авторизации на GitHub/GitLab.

# Шаг 0: проверим, вдруг ключ у нас уже есть

Ключи хранятся в папке: `~/.ssh`, где `~` это домашняя папка пользоватяля. 

Для windows:
* Откройте проводник
* Поищите скрытую папку C:\Users\ВашеИмя\.ssh
* Если скрытых папок (начинаются с точки) не видно — нужно включить скрытые файлы:
* * Вверху нажмите "Вид"
* * Поставьте галочку "Скрытые элементы"

Для mac:
* Откройте finder
* Зайдите в домашнюю папку пользователя
* Нажмите комбинацию `Cmd + Shift + .` для показа скрытых папок
* Поищите папку `.ssh`

Linux:
* Откройте терминал
* Выполните `ls -a ~/.ssh`

Если вы видите в папке файлы вроде `id_rsa` или `id_ed25519`, то ключ уже создан. Переходите сразу к шагу 2.

# Шаг 1: генерируем ssh-ключи

Для windows:
* Откройте терминал (`Win + R` -> введите в окне `cmd` -> `enter`)

Для mac:
* Откройте терминал (Откройте Spotlight `Cmd + Space` -> Введите `Terminal` -> `enter`)

Linux:
* Откройте терминал (вы явно знаете как это сделать, раз установили linux)

Выполните команду:
```bash
ssh-keygen -t rsa -b 4096 -C "your_email@example.com"
```
Далее вам зададут несколько вопросов, на которые не нужно отвечать. Ничего не вводите, просто нажимайте enter несколько раз,
пока процесс не закончится.

Сходите в папку .ssh (описал выше как ее найти) и убедитесь в наличии новых файлов `id_rsa` и `id_rsa.pub`.

# Шаг 2: регистрируем ключ в GitHub/GitLab

Файл без расширения (можно проверить через свойства) это приватный ключ. Никогда его никуда не отправляйте
и не трогайте.

Нам нужен публичный ключ, лежащий в файле с расширением `.pub`. Например `id_rsa.pub` или `id_ed25519.pub`.
Откройте его в блокноте (**не в word!!!**) и полностью скопируйте содержимое.

Добавляем ключ в GitHub:
* зайдите на https://github.com и войдите в аккаунт
* в правом верхнем углу нажмите на аватар
* выберите Settings
* слева выберите SSH and GPG keys
* нажмите New SSH key
* в поле Title — напишите что-то вроде: My Laptop
* в поле Key вставьте скопированный публичный ключ
* нажмите Add SSH key
* подтвердите пароль

Добавляем ключ в GitLab:
* Зайдите на https://gitlab.com/ и войдите в аккаунт
* нажмите на аватар (справа вверху)
* выберите Preferences или Settings
* перейдите в раздел SSH Keys
* в поле Title — напишите что-то вроде: My Laptop
* в поле Key вставьте публичный ключ
* Нажмите Add key
* подтвердите пароль

# Шаг 3: проверка

Попробуйте вбить в терминале: `ssh -T git@github.com` или `ssh -T git@gitlab.com` - должны увидеть приветствие.

Попробуйте склонировать **приватный** репозиторий через ssh.

**Внимание!** Всегда используйте клонирование через ssh, а не https.
* Вот такую ссылку НЕ ВЫБИРАЙТЕ: https://github.com/username/repository.git
* Выбирайте такую: git@github.com:username/repository.git

Вы замечательны!
